# Bank Loan Performance Dashboard

## Project Overview
Analyzed 500+ loan records to identify default patterns, 
payment trends, and borrower demographics.

## Tools Used
- Power BI
- DAX Measures
- Data Source: Kaggle

## Dashboard Pages
1. Summary - KPI Cards (Total Loans, Default Rate, Avg Amount)
2. Loan Analysis - Charts by Education, Gender, Loan Status
3. Risk Analysis - Default by Terms, Age vs Past Due Days

## Key Insights
- 20% Default Rate identified
- College educated borrowers took most loans
- 30-day term loans had highest default rate
- Male borrowers were 80% of total loans
